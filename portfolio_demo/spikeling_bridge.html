Tribe · Spikeling · real, runnable, verified this session

A spiking neural network drives NPC minds — and a local LLM speaks from their real state

Tribe is a Godot NPC trust/loyalty simulation. Every member's "brain" is a real spiking neural network (leaky integrate-and-fire neurons, Spikeling), not a behavior tree or a state machine wearing a neuroscience name. This page walks through the actual code, then runs it live: a betrayal event drives real membrane-potential dynamics, a topologically-inspired memory chain decides how vividly it's recalled, and a local LLM (Ollama, llama3.2) generates dialogue conditioned on that live numeric state — not a script.

GDScript / Godot Spikeling SNN engine LIF neurons + Hebbian synapses SSH topological memory Ollama / llama3.2, local

01The pipeline

Every NPC has one live SNN as its brain. A game event stimulates a neuron; membrane potential integrates, leaks, and eventually crosses threshold and fires; a small numeric snapshot of that state is turned into plain-English facts; those facts become the LLM's persona prompt. The arrow only ever points one way — the LLM reads the brain, it never writes back into it.

02The real neuron

No framework underneath this — spikeling.gd is a from-scratch leaky integrate-and-fire implementation. One step() call advances every neuron in the network: leak, integrate incoming stimulus, check threshold, fire, propagate to synaptic targets for next tick.

# spikeling.gd -- the actual step() function every NPC brain calls once per tick
func step() -> Array:
    for i in range(neurons.size()):
        var n: Neuron = neurons[i]
        if n.refr_left > 0:
            n.refr_left -= 1
            continue
        n.p -= n.leak                      # leaky integration
        if n.p < 0.0: n.p = 0.0
        n.p += _pending.get(i, 0.0)        # incoming stimulus
        if n.p >= n.threshold:
            n.p = 0.0
            n.refr_left = refractory_ticks
            n.fired = true
            for s in synapses:
                if s.src == i:
                    next_pending[s.dst] += s.weight   # lands NEXT step
    _pending = next_pending

Each personality is a genuinely different brain, not a different label on the same one — a "Trusting" NPC has a stronger contribute→trust synapse and a slower-leaking Trust neuron than a "Wary" one:

# tribemember.gd -- the real, personality-specific .spk brain text
neuron SawBetray     threshold=50  leak=20
neuron Trust          threshold=100 leak=2        # "Steady": leak=2, "Wary": leak=4
neuron Follow          threshold=100 leak=5
synapse SawContribute -> Trust weight=80
synapse SawBetray     -> Trust weight=-160        # strong enough to dominate any same-tick positive
synapse Trust          -> Follow weight=120

03Memory with a real physics finding underneath it

This is the part that ties back to the rest of my research: a prior real result from a topological-phononics simulation study — an SSH (Su-Schrieffer-Heeger) chain protects information at its edges against disorder far better than in its bulk — is wired into an actual NPC feature, not just cited. Each NPC gets a small 12-neuron SSH-style chain as its "core memory." A witnessed betrayal is written to an edge slot (1–2 hops from a chain boundary); a routine slight goes to a bulk slot (5–6 hops). Real panic calls apply_stress(), which jitters the chain's synapse weights — the same disorder mechanism the original physics experiment measured.

# npc_core_memory.gd -- recall confidence is the WEAKEST hop margin
# on the path from the chain's nearest boundary to the memory's slot
func recall(tag: String) -> float:
    var slot: int = _tag_to_slot[tag]
    var min_margin: float = 1.0
    # walk hop-by-hop from the nearest boundary; the chain is only
    # as strong as its weakest link along that path
    while idx != slot:
        min_margin = minf(min_margin, _hop_margin(idx, nxt))
    return min_margin

05Why it's built this way

The LLM never sees a hand-written mood label. It sees real numbers pulled straight off a live spiking network — a membrane potential, a hop-margin recall confidence — turned into plain sentences. Two NPCs with the same social rank but different lived history sound different, because their underlying Trust neurons genuinely hold different values, not because a designer wrote branching dialogue for each case. The dependency runs one way only: the SNN is the source of truth, the LLM is a renderer for it.
